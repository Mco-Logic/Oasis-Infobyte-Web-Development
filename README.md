This repository contains my submissions for **Level 1 tasks** as part of the **Web Development and Web Design Internship** at **Oasis Infobyte**. The projects showcase core web technologies, user experience principles, responsive design, and interactive frontend development.

---

## 🚀 Projects Included

### 1. 🛬 Landing Page (Task 1)
* **Description:** A modern, visually engaging landing page designed for product or service promotion.
* **Key Features:**
  * Clean hero section with call-to-action (CTA) buttons.
  * Structured feature sections highlighting services and benefits.
  * Fully responsive layout adapted across modern devices.

---

### 2. 🌡️ Temperature Converter Website (Task 2)
* **Description:** An interactive web utility tool that performs real-time temperature scale conversions.
* **Key Features:**
  * Supports conversions between **Celsius**, **Fahrenheit**, and **Kelvin**.
  * Instant processing with clear input validation.
  * Minimalist, user-friendly UI designed for seamless usability.

---

### 3. 💼 Personal Portfolio (Task 3)
* **Description:** A clean, professional online portfolio demonstrating frontend projects, personal skill sets, and contact channels.
* **Key Features:**
  * **About Me** section showcasing background and goals.
  * **Skills Overview** highlighting core technologies and web toolkits.
  * **Projects Showcase** displaying practical implementations.
  * **Contact Section** with social and professional channels.
